05 / DEEP DIVE

把公式拆开，看见每一步。

从一个标量神经元，到可以训练分类器的多层网络。下面这些知识点是理解 BP 的主干。

01

神经元在计算什么？

神经元先做加权求和，再通过激活函数。权重决定信号放大还是削弱，偏置决定整体平移。

z = Σ(wᵢxᵢ) + b

如果没有激活函数，多层线性层叠加后仍然只是一个线性变换，无法表达 XOR 这种非线性关系。

02

为什么要用损失函数？

训练需要一个可以优化的目标。均方误差适合回归，二元交叉熵更适合二分类。

L = −[y log(ŷ) + (1−y)log(1−ŷ)]

损失不是准确率。准确率只告诉你对了多少，损失还会告诉模型“错得有多自信”。

03

链式法则怎么接起来？

参数不会直接连到损失，中间隔着多层函数。链式法则把每一段局部导数相乘，得到完整影响。

∂L/∂w = (∂L/∂ŷ)(∂ŷ/∂z)(∂z/∂w)

反向传播不是另一种训练算法，而是高效计算梯度的方法。

04

梯度下降在做什么？

梯度指向损失增长最快的方向。减去梯度，就像沿山坡向下走；学习率决定每一步有多大。

θₜ₊₁ = θₜ − η∇L(θₜ)

学习率过大可能来回震荡，过小则训练很慢，甚至看起来像“学不会”。

05

Batch、Epoch、Iteration

Batch 是一次送入网络的样本子集；Iteration 是更新一次参数；Epoch 是完整遍历一遍训练集。

1 epoch = N / batch_size iterations

小 batch 更新更频繁、噪声更大；大 batch 更稳定，但占用更多内存。

06

梯度消失与梯度爆炸

深层网络连续相乘导数，可能越来越小或越来越大。Sigmoid 在饱和区梯度接近 0，容易出现梯度消失。

σ′(z) = σ(z)(1−σ(z))

常见缓解方法包括 ReLU、合理初始化、归一化和残差连接。

06 / ALGORITHM CARD

把 BP 写成
一段流程。

看懂伪代码后，你会知道框架里的 fit、loss 和 optimizer 分别在做什么。

BACKPROPAGATION.PSEUDO07 STEPS
01 初始化权重 W 和偏置 b
02 对每个 batch 做前向传播：z = Wx + b，a = σ(z)
03 用预测值 a 和标签 y 计算损失 L
04 从输出层开始，按链式法则计算 ∂L/∂W 和 ∂L/∂b
05 更新参数：W ← W − η · ∂L/∂W
06 更新偏置：b ← b − η · ∂L/∂b
07 重复多个 epoch，直到验证集表现稳定

07 / CHOOSE THE RIGHT TOOL

激活函数
怎么选？

函数输出范围优点常见位置
Sigmoid(0, 1)可解释为概率二分类输出层
ReLU[0, +∞)计算简单，缓解梯度消失隐藏层默认选择
tanh(−1, 1)零中心，表达平滑部分隐藏层
Softmax总和为 1输出多类别概率多分类输出层
