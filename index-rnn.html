01 / 输入

为什么是 28 个时间步？

MNIST 图片尺寸是 28×28。把每一行看作一个时间步，每步有 28 个像素特征，RNN 就能沿着行读取整张图。

x.shape = (batch, 28, 28)
02 / 记忆

SimpleRNN 保留什么？

每一步根据当前输入 xₜ 和上一步隐藏状态 hₜ₋₁ 计算新的 hₜ。这个状态就是网络对“已经读过的内容”的压缩记忆。

hₜ = tanh(Wxₜ + Uhₜ₋₁ + b)
03 / 堆叠

为什么前两层返回序列？

下一层 RNN 需要看到完整的时间序列，所以前两层设置 return_sequences=True。最后一层只取最后状态，交给 Dense 分类。

return_sequences=True → False
04 / 输出

Softmax 如何变成概率？

Dense 层产生 10 个 logits，Softmax 把它们归一化为总和为 1 的概率。最大概率对应最终预测数字。

ŷᵢ = exp(zᵢ) / Σⱼ exp(zⱼ)
05 / 训练

compile 配置了什么？

Adam 根据梯度自适应调整步长；sparse categorical crossentropy 适用于标签是整数 0–9 的多分类任务；accuracy 便于观察分类正确率。

optimizer='adam'
06 / 泛化

validation_split 为什么重要？

训练集中的 10% 不参与参数更新，只用于监控模型对未见数据的表现。如果训练准确率上升而验证准确率下降，可能发生过拟合。

validation_split=0.1

04 / REPRODUCIBLE CODE

完整实验
代码卡片。

下面的代码结构对应报告中的实现，可复制到 TensorFlow/Keras 环境运行。

RNN_MNIST_EXPERIMENT.PY
import numpy as np
import matplotlib.pyplot as plt
from tensorflow.keras.datasets import mnist
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import SimpleRNN, Dense, Activation

(x_train, y_train), (x_test, y_test) = mnist.load_data()
x_train = x_train.reshape(-1, 28, 28) / 255.0
x_test = x_test.reshape(-1, 28, 28) / 255.0

cell_size = 128
output_size = 10
model = Sequential()
model.add(SimpleRNN(128, return_sequences=True, input_shape=(28, 28)))
model.add(SimpleRNN(128, return_sequences=True))
model.add(SimpleRNN(128))
model.add(Dense(output_size))
model.add(Activation('softmax'))

model.compile(optimizer='adam',
              loss='sparse_categorical_crossentropy',
              metrics=['accuracy'])
history = model.fit(x_train, y_train,
                    batch_size=64, epochs=10,
                    shuffle=True, validation_split=0.1)
loss, accuracy = model.evaluate(x_test, y_test)
predictions = model.predict(x_test)
